# UNIT·CONTROL — проект настроек и данных (для отдельного проекта на Арене)

Это свод всех настроек, данных и решений, принятых при разработке приложения
UNIT·CONTROL (юнит-экономика для маркетплейсов, репозиторий `ccchibsss/ccchibsss`).
Папка подготовлена так, чтобы её можно было открыть как **отдельный проект на
Арене** и работать с настройками/данными независимо от кода приложения.

## Как открыть отдельным проектом на Арене
1. Создайте новый проект/чат на Арене.
2. Укажите этот репозиторий и попросите работать с папкой `arena-project/`
   (или скопируйте папку в отдельный репозиторий и подключите уже его).
3. Точка входа — этот README; дальше — файлы ниже.

## Состав
| Файл | Что внутри |
|---|---|
| `settings.snapshot.json` | Машиночитаемый снимок ключевых настроек приложения (без секретов) |
| `settings.md` | Настройки по-человечески: импорт, обогащение, экономика, маркетплейсы |
| `data.md` | Данные: прайс, кросс-листы, экспорты — структура и статистика (сами файлы сюда не кладём) |
| `decisions.md` | Решения из чата, которые нельзя терять и «переизобретать» |
| `versions.md` | История версий и PR: что и когда менялось |

## Чего здесь НЕТ и не должно быть
- **Секреты**: токены API маркетплейсов, `secret`, ключи GAS — они живут только
  в настройках приложения в браузере (`secretMemoryOnly`) и в проект не выносятся.
- **Сами файлы данных**: прайс 22 МБ и кросс-листы в git не кладём — в `data.md`
  только их описание и статистика, файлы хранятся у владельца.

## Источник правды
Приложение — монофайл `index.html` в корне репозитория. Если настройка в этом
проекте разошлась с кодом приложения — прав код, а снимок надо обновить
(значения по умолчанию берутся из объекта `S.settings` в `index.html`).
