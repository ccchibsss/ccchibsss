# Настройки приложения

Значения по умолчанию из `S.settings` (`index.html`), сгруппированы по смыслу.
Живые значения у пользователя могут отличаться — они хранятся в браузере
(IndexedDB, таблица meta) и в этот проект не синхронизируются автоматически.

## Импорт и обогащение
- Ключ каталога: **артикул+бренд** (`keyMode: 'article+brand'`).
- Первый файл — прайс, он задаёт состав каталога. Дальше обогащение идёт
  **только по текущему прайсу** (`importEnrichOnly: true`): новые файлы не
  создают SKU вне прайса.
- Ключи поиска SKU для обогащения — ровно два: **артикул+бренд** и **уникальный
  OE-номер**. Поиск по аналогам запрещён (см. `decisions.md`).
- Обогащение связанных строк каталога при импорте — включено
  (`enrichRelatedOnImport: true`).
- **Лёгкий импорт**: экономика не считается при загрузке; каталог ~0,45 КБ/SKU,
  досчёт при экспорте или входе в расчётные разделы. После экспорта расчётные
  поля сбрасываются (`releaseEconomics`).
- **Дисковый импорт (v12.9.93)**: кнопка «Прайс + кроссы — сразу в приложение».
  Потоковый CSV → пакеты по 2 000 строк в IndexedDB, кроссы — только OE-индекс,
  только CSV, только полная замена каталога, маппинг автоматический.

## Экономика
- Основная площадка: **Ozon** (`activeMarketplace: 'OZON'`), считается одна
  площадка (`calcSelectedMpOnly: true`) — «Сравнение» в шапке включает все пять.
- Фулфилмент: FBS. Налог: УСН «доходы» 6% (`taxRegime: 'usn_income_6'`, `taxPct: 6`).
- Объёмный вес: делитель 5000. Базовая наценка на закупку: 30%
  (`markupBasePct`), цена не опускается ниже безубыточности
  (`markupIgnoreBreakEven: false`). Наценка BE: 25%. Целевая маржа: 20%.
- Комиссии по умолчанию: Ozon 14% + эквайринг 1,5%; WB 15% + 1,5%
  (логистика 46 ₽ + 14 ₽/литр, коэф. склада 1,7); МегаМаркет 12%; Авито 6%.
  Это стартовые значения — реальные ставки задаются тарифами и настройками.

## Стандартные (типовые) ОВХ
- `autoStdDims: false` — в каталог стандартные габариты **не записываются**
  (жёсткое правило с v12.9.67).
- Расчёт по стандартным ОВХ (`calcStdDims`): временная подстановка типовых
  значений только в пустые поля и только при точном (exact) совпадении
  стандарта; SKU помечается, в выгрузке подсвечивается **#FFA07A**.

## Аномалии и карантин
- SKU с аномальными весогабаритами блокируются для расчётов и выгрузок до
  исправления или явного подтверждения (подпись «значения+категория+лимиты»).
- Заблокированные SKU не попадают в экспорт и комплект повторной загрузки —
  перед выгрузкой счётчик «заблокировано» должен быть 0.

## Синхронизация и лимиты
- Бэкенд: custom server / GAS; пакет синхронизации — 2 000 строк.
- Google Sheets рекомендована до ~20 000 SKU; локальный режим (IndexedDB) —
  до ~300 000 SKU. MemGuard: soft 700 МБ / hard 950 МБ (эвристика без
  `performance.memory`), при давлении — автосброс расчётных полей (v12.9.94).
