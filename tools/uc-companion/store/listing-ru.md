# Материалы для Chrome Web Store (заполнить в кабинете разработчика)

Название: UNIT CONTROL — отправка цен и остатков
Категория: Производительность (Productivity)
Язык: Русский

Краткое описание (132 символа):
Цены и остатки из UNIT CONTROL в Ozon прямо из браузера — без серверов и лишних программ.

Подробное описание:
Расширение-компаньон для пользователей UNIT CONTROL. Передаёт цены и остатки
в API Ozon прямо из браузера: страница приложения не может обращаться к API
площадок из-за CORS, а расширение с вашего разрешения — может.

Как пользоваться:
1. Установите расширение и впишите Ozon Client-Id и Api-Key в его настройках.
2. Откройте UNIT CONTROL как обычно.
3. При отправке цен приложение само предложит компаньона, если локальный
   движок UNIT CONTROL не запущен.

Безопасность:
- Ключи площадок хранятся только в локальном хранилище расширения и никогда
  не передаются в страницу приложения или третьим лицам.
- Расширение не собирает аналитику, не содержит рекламы и удалённого кода.
- Весь код расширения открыт (репозиторий проекта).

Единая цель (single purpose): передача цен и остатков из UNIT CONTROL в API
площадок по запросу пользователя из интерфейса UNIT CONTROL.

Обоснование разрешений:
- storage: хранение ключей площадок, введённых пользователем.
- host_permissions (api-seller.ozon.ru, *.wildberries.ru, api.partner.market.yandex.ru):
  запросы к API площадок от имени пользователя; страница не может делать их
  из-за CORS. Запросы выполняются только по команде из UNIT CONTROL.
- content script только на 127.0.0.1/localhost: мост postMessage между
  локально открытым UNIT CONTROL и расширением.

Заметки для проверяющего (review notes):
Расширение работает в связке с локальным приложением UNIT CONTROL
(открывается по адресу http://127.0.0.1:8765). Без приложения расширение
пассивно: content script только слушает postMessage с локальной страницы.
Для полной проверки нужен тестовый продавец Ozon (Client-Id/Api-Key вводятся
в настройках расширения); отправка цен — POST api-seller.ozon.ru/v1/product/import/prices.
