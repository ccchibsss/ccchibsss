# Публикация компаньона в Chrome Web Store — пошагово для владельца

Это делается один раз с вашего аккаунта Google. Код и пакет уже готовы.

1. Зарегистрируйтесь как разработчик: https://chrome.google.com/webstore/devconsole
   (разовый платёж Google 5 $, нужна карта и подтверждение личности).
2. «Новый элемент» → загрузите файл `tools/uc-companion-store.zip`
   (пересобрать после правок: `python tools/uc-companion/build_store_zip.py`).
3. Заполните карточку из `listing-ru.md`: название, описания, категория.
4. Загрузите скриншоты 1280x800 (снять по списку из listing-ru.md).
5. Политика конфиденциальности: опубликуйте `privacy-policy.md` по публичному
   URL (проще всего — GitHub Pages репозитория) и вставьте ссылку в форму.
6. В разделе «Конфиденциальность» вставьте обоснования разрешений из listing-ru.md.
7. Отправьте на проверку. Срок — от пары дней до нескольких недель; частый
   вопрос проверяющих — зачем host_permissions, ответы уже написаны.

После одобрения:
- У расширения появится страница в магазине; пользователи ставят его одной
  кнопкой «Установить» — руководство UNIT CONTROL просто даёт ссылку.
- Тот же zip подходит для Microsoft Edge Add-ons (отдельная подача, бесплатно).
- Яндекс Браузер ставит расширения из Chrome Web Store напрямую.

Обновления: правка кода → поднять version в manifest.json → пересобрать zip →
загрузить в той же карточке → короткая повторная проверка.
