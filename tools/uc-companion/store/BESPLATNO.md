# Бесплатная публикация компаньона (без Chrome Web Store за 5 $)

Регистрация разработчика и публикация бесплатны в трёх каталогах. Пакеты
собираются скриптом build_store_zip.py из папки расширения.

## 1. Opera Add-ons — главный канал для Яндекс Браузера
Яндекс Браузер официально ставит расширения из каталога Opera, а Opera —
Chromium-совместима: нужен тот же zip, что и для Chrome.
1. Соберите пакет: `python build_store_zip.py`
2. Регистрация: https://addons.opera.com/developer/ (бесплатно, аккаунт Opera).
3. «Upload» → загрузите `uc-companion-store.zip`, заполните описание из
   listing-ru.md, загрузите иконку и скриншоты.
4. Модерация Opera — обычно дни, не недели.
После одобрения пользователи Яндекс Браузера и Opera ставят компаньона одной
кнопкой со страницы каталога Opera.

## 2. Microsoft Edge Add-ons — для пользователей Edge
Тот же Chromium-zip.
1. https://partner.microsoft.com/dashboard/microsoftedge/ — регистрация
   разработчика Edge бесплатная (в отличие от Chrome Web Store).
2. «New extension» → тот же `uc-companion-store.zip`, тексты из listing-ru.md,
   политика конфиденциальности — публичный URL на privacy-policy.md.
После одобрения — установка одной кнопкой в Edge.

## 3. Firefox (AMO) — если среди пользователей есть Firefox
1. Соберите вариант: `python build_store_zip.py firefox`
   (скрипт сам меняет background на scripts и добавляет gecko id).
2. https://addons.mozilla.org/developers/ — бесплатно. Можно опубликовать
   открыто или «unlisted» (подписанный XPI для своей ссылки на скачивание).

## Чего бесплатно не бывает
- Chrome Web Store: разовый платёж разработчика 5 $ — политика Google.
  Пользователям обычного Chrome без магазина остаётся установка из папки
  (USTANOVKA.bat, режим разработчика) — это тоже бесплатно и уже работает.

## Что дать пользователям
Одна страница-инструкция: «Поставьте компаньон» со ссылками на Opera
(для Яндекс Браузера) и Edge + USTANOVKA.bat для Chrome. Приложение находит
установленного компаньона само.
