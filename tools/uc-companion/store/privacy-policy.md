# Политика конфиденциальности расширения «UNIT CONTROL — отправка цен и остатков»

Дата: 2026-11-08.

Расширение не собирает, не хранит на серверах и не передаёт третьим лицам
персональные данные пользователей.

Что хранится локально:
- Ozon Client-Id и Api-Key, которые пользователь сам вводит в настройках
  расширения. Они хранятся в локальном хранилище браузера
  (chrome.storage.local) на устройстве пользователя и используются только
  для запросов к API Ozon (api-seller.ozon.ru) от имени пользователя.

Что передаётся по сети:
- Только запросы к API площадок (Ozon; в будущих версиях — Wildberries и
  Яндекс Маркет), инициированные пользователем из интерфейса UNIT CONTROL:
  артикулы товаров, цены и остатки. Получатель — только соответствующая
  площадка. Никакой аналитики, телеметрии, рекламы и удалённого кода.

Удаление данных: удаление расширения стирает все его локальные данные.
Контакт: репозиторий проекта UNIT CONTROL (GitHub Issues).
