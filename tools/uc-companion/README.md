# UNIT CONTROL — расширение-компаньон

Передаёт цены и остатки из приложения в API площадок **прямо из браузера**:
без Python-движка, без GAS и без своего сервера.

## Почему страница сама так не может
Страница приложения не имеет права делать запросы к `api-seller.ozon.ru`
из-за CORS: API площадок не отдаёт `Access-Control-Allow-Origin`, и браузер
блокирует и запрос, и чтение ответа. Расширение с `host_permissions` этим
ограничением не связано — запросы выполняет его background service worker.

## Установка (один раз, 2 минуты)
Самый короткий путь: запустите **USTANOVKA.bat** из этой папки — он откроет
страницу расширений и папку, останется перетащить папку на страницу.
Вручную:
1. Откройте `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите эту папку `tools/uc-companion`.
4. Откройте настройки расширения и впишите Ozon Client-Id и Api-Key.
   Ключи хранятся только в хранилище расширения и в страницу не передаются.

## Как работает
- Приложение определяет компаньона само (ping через postMessage).
- Очередь цен: движок выключен + компаньон установлен → приложение спрашивает
  подтверждение и отправляет цены в Ozon напрямую из браузера.
- Приоритет каналов: Python-движок (очередь, dry-run по умолчанию) →
  компаньон (прямая отправка с подтверждением) → файл экспорта в кабинет.

## Ограничения v1
- Только Ozon: цены (`/v1/product/import/prices`) и остатки
  (`/v2/products/stocks`, нужен warehouse_id в строках).
- Работает на страницах `http://127.0.0.1` и `http://localhost` (приложение,
  открытое через движок или локальный адрес). Для file:// включите расширению
  «Разрешить доступ к URL файлов» на странице расширений.
- WB и Яндекс Маркет: host_permissions уже заявлены, обработчики — следующими
  версиями (WB нужны nmID, ЯМ — campaign/business id и своя схема цен).
