# v12.9.59 — возврат импорта (hotfix к v12.9.57)

## Что случилось

В v12.9.57 раздел ABC/XYZ удалялся скриптом, который вырезал метод `Dash.renderMatrix`
по границе «до строки `},`». Метод был **последним** в объекте `Dash` и заканчивался
`}` + `};`, поэтому поиск границы ушёл дальше и вырезал лишнее:

| Вырезано сверх задуманного | Следствие |
|---|---|
| `};` — закрытие объекта `Dash` | все методы следующего объекта «уехали» в `Dash` |
| заголовок раздела «16. Импорт / маппинг» | — |
| `const DEMO_IMPORT_CSV = …` | пропал демонстрационный набор |
| `const Import = {` и метод `pick()` | **импорт перестал существовать**: любое нажатие «Импорт» падало с `ReferenceError: Import is not defined` |

Плюс отдельная строка: при удалении накопления матрицы ABC×XYZ в `Dash.agg`
осталась строка `mc.n++; mc.pr += …` без объявления `const mc`, поэтому
`Dash.agg()` падал с `ReferenceError: mc is not defined` — дашборд не строился.

Смоук-тест версии проверял пересчёт и таблицу, но не вызывал импорт и не строил
агрегат дашборда, поэтому обе поломки прошли незамеченными.

## Что сделано

1. Удалена осиротевшая строка `mc.n++; mc.pr += p.netProfit || 0; …` в `Dash.agg`.
2. Восстановлены закрытие `Dash` (`};`) и блок из 27 строк: заголовок раздела 16,
   комментарий демо-данных, `DEMO_IMPORT_CSV`, `const Import = {`, `pick() { … },` —
   ровно в том виде, в каком они были в v12.9.56. Методы `demo/read/guessProfile/
   normalize/apply/…` остались на месте и снова принадлежат `Import`.

## Проверки

- `node --check` клиентского блока — OK; баланс разметки 1 740 / 1 740.
- `typeof Import` → `object`, `typeof DEMO_IMPORT_CSV` → `string`,
  `Object.keys(Dash)` → `period, charts, _agg, agg, kpis, spark, render` (лишних методов нет).
- `Dash.agg()` на тестовой строке — `ok`.
- Полный импорт синтетического файла на 3 000 строк через `Import.apply()`:
  **4,0 с** (пересчёт и запись 2,9 с), 3 000 строк, у всех посчитана чистая прибыль.

## Урок на будущее

Границы удаляемых блоков нужно проверять по содержимому (первая и последняя строка
вырезанного фрагмента), а после каждой такой правки — прогонять не только пересчёт,
но и **импорт + агрегат дашборда**. Эти две проверки добавлены в смоук-набор.
