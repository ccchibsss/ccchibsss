# v12.9.69 — раздельный режим обогащения категорий/ТН ВЭД

Дата: 2026-11-08 · Клиент: `12.9.69-client+enrich-catmode` · Ветка: `arena/45cbf108-ccchibsss`

Внедрены рекомендации по критериям обогащения: точный ключ — для юридически
значимых полей, OE-аналоги — только там, где ошибка не критична.

## Что изменено

### 1. Отдельный способ обогащения для категории и ТН ВЭД
- Новая настройка `enrichCatMode` с тремя значениями: `artbrand` (по умолчанию),
  `oe`, `auto`. В интерфейсе — второй переключатель рядом с общим «Способ
  обогащения» (блок обогащения Каталога V) с контекстной подсказкой.
- `HVC.enrichOne` теперь делает два раздельных неразрушающих прохода:
  - `main` — название, применимость, ОВХ, аналоги, группа, штрихкод — общим
    способом `enrichMode`;
  - `cat` — только категория и ТН ВЭД — способом `enrichCatMode`.
- По умолчанию категория и ТН ВЭД берутся **только от той же пары
  Артикул+Бренд**: OE-аналог может быть другим товаром, а чужие категория и
  код ТН ВЭД — юридический риск (Честный знак, таможня).
- Групповой гейт внутри `_enrichOneWithMode(p, scope, mode, grp)`:
  `grp='main'` не трогает категорию/ТН ВЭД, `grp='cat'` — только их.
  Оба прохода по-прежнему заполняют только пустые поля.

### 2. Категория по OE — только при единогласии доноров
- `_oeAggOf` собирает множество всех осмысленных категорий доноров OE
  (`aggCats`), `_oeSetOf` объединяет их по всем OE строки (включая прямой
  OE-реестр) в `cats`/`catConflict`.
- Если доноры расходятся (>1 разной категории) — категория по OE **не берётся
  вовсе** (раньше бралось первое непустое значение); габариты, название и
  применимость при этом обогащаются как прежде.
- Заглушки «Без категории»/«Разное»/«Прочее»/«Не определено» донорами не
  считаются.

## Что сознательно не менялось
- GAS-каскад обогащения на сервере (прямое OE → связанные → аналоги):
  серверный путь оставлен как есть, правило единогласия действует в клиенте.
- Автоподбор категорий по названию и файл категорий по Артикул+Бренд —
  критерии и защита «только пустые поля» прежние.

## Проверка
`node tests/run-tests.js` — OK. Помимо прежних проверок добавлены
функциональные тесты на реальном объекте HVC (стенд без зависимостей):
режим по умолчанию `artbrand`; конфликт категорий OE-доноров → категория
пуста и `catConflict=true`; единогласие → категория берётся; `enrichOne`
заполняет категорию и ТН ВЭД именно от пары Артикул+Бренд (проверяется
источник в `_sources`), даже при общем режиме `oe`.
