# v12.9.88 — Исправления по аудиту лёгкого режима

## 1. Лёгкое состояние переживает перезагрузку (главное замечание аудита)
- `persistEconPending()`: флаг `S._econPending` пишется в `localStorage`
  (`uc.econPending`) при установке (лёгкий импорт, сброс после экспорта) и при
  снятии (полный расчёт).
- Старт: флаг восстанавливается до стартового пайплайна; пайплайн запускается с
  `skipEconomics`, если каталог лёгкий. Если стартовый экран расчётный
  (дашборд/данные/экспорт и т.д.) — экономика досчитывается сразу через
  `ensureEconomics()`; если нет (Аномалии, Категории и пр.) — старт лёгкий,
  досчёт произойдёт при входе в расчётный раздел.
- Сводный тост пайплайна на старте в лёгком режиме подавлен.

## 2. MemGuard-эвристика: пороги выше
Без `performance.memory` оценка грубее измерения, поэтому для эвристического
режима пороги подняты: soft 700 / hard 950 МБ (вместо 600/800), чтобы сбросы
кэшей не срабатывали раньше реального давления памяти на больших каталогах.

## 3. Сброс после экспорта не оставляет текстовые итоги
`releaseEconomics()` дополнительно очищает `recommendation` и
`economicsDataQuality` — текстовые итоги экономики не переживают сами цифры.

## 4. Экспорт подмножества не перестраивает таблицу
Досчёт для экспорта идёт с `preserveView: true`: срез таблицы и воркер фильтра
не сбрасываются и не перерисовываются под окном прогресса экспорта.

## Проверка
- `node tests/run-tests.js` — OK (+ ассерты persist/boot/порогов/preserveView).
- Стенд на настоящих фрагментах: сохранение/восстановление флага; release
  очищает цифры и тексты, входные поля целы, флаг сохранён; boot-правило
  по стартовому экрану.
