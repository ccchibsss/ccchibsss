# Передача цен и остатков без Python: каналы и выбор

Вопрос: как отдавать цены/остатки в площадки, если Python-движок не запущен.
Страница в браузере упирается в CORS (API площадок не разрешают запросы со
сторонних origin), поэтому «просто fetch из вкладки» не работает. Рабочие каналы:

| Канал | Что нужно | Отправка | Минусы |
|---|---|---|---|
| Python-движок (outbox) | запущенный exe | очередь, dry-run по умолчанию, идемпотентно | нужен включённый ПК с движком |
| **Расширение-компаньон (v12.9.138)** | установить `tools/uc-companion` один раз | напрямую из браузера, с подтверждением | только Ozon в v1; ручная установка |
| GAS-прокси (уже в приложении) | развёрнутый Apps Script | через Google, с дельта-очередью в Sheets | зависимость от Google, настройка |
| Файл экспорта Ozon | ничего | вручную в кабинете | не автоматично |

## Реализовано: расширение-компаньон
- MV3, `host_permissions` на API Ozon/WB/ЯМ снимают CORS для background worker.
- Content script на 127.0.0.1/localhost мостит postMessage: страница →
  расширение → API площадки → ответ в страницу.
- Ключи площадок живут только в `chrome.storage.local` расширения; страница
  их не видит и не может украсть вредоносным скриптом.
- Интеграция: `Companion.available()/send()` + приоритет в
  `PyEngine.enqueuePrices`: движок → компаньон → подсказка про файл.
- Реальная отправка — только после явного confirm с числом позиций.
