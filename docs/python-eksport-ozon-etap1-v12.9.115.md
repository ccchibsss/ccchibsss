# v12.9.115 — Выгрузка OZON на движке, этап 1

Механика доставки файла была готова в v12.9.108; здесь портировано ядро
построителя строки шаблона Ozon (46 колонок) и поля карточки.

## Что сделано

- Схема products расширена полями карточки (миграция): barcode,
  image_url, extra_photos, ozon_sku, ozon_type, ozon_category, model,
  hazard_class, color, material, country, warranty, diameter,
  package_contents, rich_content, description, mark_required,
  group_articles, cross_numbers, multiplicity, net_weight, old_price.
  _syncCatalog приложения шлёт их из строк каталога.
- `ozon_row()` движка — портированные правила приложения:
  цена не выдумывается (нет цены — пустая ячейка и ошибка в колонке 44);
  зачёркнутая цена — только явная старая выше цены или надбавка,
  выбранная продавцом (discount_pct из настроек приложения);
  вес кг→г, размеры см→мм с сортировкой длина≥ширина≥высота;
  OEM через «; », альтернативные артикулы без дублей с артикулом/OEM;
  аннотация — описание или «Название. Артикул детали: … Производитель: …»;
  хештеги #автозапчасти #запчасти #бренд; подмножество проверки в
  колонках «Ошибка/Недочёты» (бренд, тип, ТН ВЭД, ОВХ, фото, цена, штрихкод).
- Эндпоинт GET /export/ozon.csv?discount_pct&vat&enc; кнопка приложения
  «Python: экспорт OZON» скачивает UC_ozon_engine.csv.

## Проверки

- unittest TestOzonExport: 46 колонок, округление цены, граммы,
  сортировка габаритов (80/60/100), кратность, OEM, аннотация,
  пустая цена даже со скидкой, явная старая цена, надбавка 30% → 130.
  Движок 29/29.
- Живой цикл: импорт карточки → CSV: 46 колонок, вес 300 г,
  Ш×В×Д 80×60×100 мм, OEM «OE1; OE2», ошибок нет.

- Пары «категория → тип» OzonReference и словарь типов Seller API:
  движок берёт ozon_type/ozon_category как есть из синка приложения.
- Источники ТН ВЭД/гарантии/страны по справочникам (ozonSourceAttributes),
  автоподстановка категорий, стандартные ОВХ при экспорте (exportDimsFor),
  Liquid-шаблоны аннотаций, фильтр «ЧЗ по списку», скоупы фильтр/выделенные
  (движок выгружает весь свой каталог), 4 служебные строки шаблона
  в XLSX-варианте и жёлтая заливка стандартных ОВХ.
- До этапа 2 браузерная выгрузка остаётся полной и основной для сложных
  случаев; движковая — быстрый CSV всего каталога с честной колонкой ошибок.
