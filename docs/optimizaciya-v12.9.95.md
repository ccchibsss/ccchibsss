# v12.9.95 — Все разделы оптимизации одним пакетом

## Сделано
- **КРИТИЧНЫЙ ФИКС дискового импорта**: строка заголовков файла обрабатывалась
  как данные (в каталог попадала лишняя «SKU» из заголовка прайса, в OE-индекс —
  мусорная связка). Проходы CSV теперь пропускают первую строку (`eachRow`).
- **п.3 · Предупреждение о карантине**: `warnQuarantinedBeforeExport()` в
  `exportGuard` (все выгрузки) и в комплекте повторной загрузки: количество
  заблокированных SKU и примеры артикулов ДО формирования файла. Раньше
  `Exp.rows()` отсекал их молча, а проверка в `_runImpl` не срабатывала.
- **п.4 · Потоковый обычный импорт**: CSV в `Import.read` разбирается
  `CsvStream.rows` кусками по 4 МБ вместо подъёма файла одной строкой.
- **п.5 · Отчёт о покрытии кроссами** в дисковом импорте: % SKU прайса с OE,
  число неоднозначных OE, пары кроссов вне прайса и топ-5 брендов без покрытия.
- **п.6 · XLSX в дисковом импорте**: книга разбирается в Web Worker
  (`DiskXlsxWorkerMain` + встроенный SheetJS из страницы), главный поток
  получает заголовки и пакеты строк; при сбое воркера — честный отказ с
  советом использовать обычный импорт. Проверено стендом на настоящем SheetJS.
- **п.9 · Снимок настроек**: кнопка «Снимок настроек» скачивает
  `settings.snapshot.json` из живых настроек (без секретов) в формате
  arena-project.
- **п.1 · Золотые фикстуры**: тесты фиксируют эталонные выгрузки владельца
  (12 SKU: состав и цены стабильны между filtered/recalculated) — фундамент
  для будущих паритетных тестов расчёта.

## Статус остальных разделов (честно)
- **п.2 · Экономика в воркере** — не перенесена: нужен паритет «главный поток
  vs воркер» копейка в копейку; золотые фикстуры (п.1) — первый шаг, воркер
  следующим отдельным проектом.
- **п.7 · Воркер фильтра** — уже работает проекциями кусками по 15 000 SKU
  (v12.9.19), второй полной копии каталога нет; колоннарная упаковка внутри
  воркера — следующий шаг при необходимости.
- **п.8 · Постраничный каталог с диска** — не делается: переписывание таблицы,
  фильтров и дашборда; порог целесообразности — каталоги 300k+ SKU.
