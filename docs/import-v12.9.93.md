# v12.9.93 — Дисковый импорт: прайс + кроссы сразу в приложение

Запрос: загружать прайс и кросс-листы так, чтобы данные писались не в оперативную
память, а в приложение (хранилище IndexedDB).

## Что сделано
Кнопка «Прайс + кроссы — сразу в приложение» (раздел «Данные»). Режим:

- Оба файла выбираются одним действием (прайс обязателен, кроссы — по желанию).
- Файлы **не поднимаются в память целиком**: `CsvStream` декодирует CSV кусками по
  4 МБ (`file.slice` + потоковый `TextDecoder`, UTF-8/windows-1251) и отдаёт строки
  по мере разбора. Парсер держит хвост в 2 символа, поэтому кавычки, `""` и `\r\n`
  на границе кусков не ломаются (проверено тестом с разрезами во всех позициях и
  стендом с кусками по 16 байт на CP1251).
- Кросс-лист **не становится строками**: из него строится только OE-индекс
  «артикул+бренд → OE» (десятки тысяч записей вместо сотен тысяч строк).
- Прайс пакетами по 2 000 строк пишется сразу в черновик IndexedDB
  (`products_stage`), затем каталог подменяется одной транзакцией (как чанковая
  запись persist). В RAM живут только текущий пакет, индекс ключей прайса и
  OE-индекс кроссов.
- Обогащение — по двум ключам, как принято с v12.9.85: артикул+бренд (OE из кроссов
  дописываются SKU прайса). Поиск по аналогам не используется.
- Дубли артикул+бренд внутри прайса: последняя строка перезаписывает первую
  (счётчик в итоговом тосте).
- Экономика не считается (лёгкий режим) — досчитается при экспорте или входе в
  расчётные разделы. После записи каталог один раз поднимается из IndexedDB,
  как при обычном старте приложения.

## Ограничения режима
- Только CSV (для XLSX/XLS — обычный импорт).
- Только полная замена каталога (дозагрузка/обогащение существующих SKU — обычный
  импорт).
- Маппинг автоматический (профиль по имени файла или автоопределение колонок).
  Нестандартные заголовки — обычный импорт с ручным маппингом.
- Рабочий каталог после загрузки по-прежнему находится в памяти вкладки
  (на нём работают таблица, фильтры и дашборд) — но в «тонком» виде лёгкого
  импорта, без поднятия файлов и без вторых копий на этапе загрузки.
