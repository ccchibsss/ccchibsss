# v12.9.113 — Fuzzy-подсказки аналогов на движке (только оператору)

Пункт 7, последний, аудита оптимизаций (docs/python-optimizacii-v12.9.107.md).

## Правило, которое не нарушено

Запрет авто-поиска аналогов (v12.9.85) в силе: движок НИЧЕГО не пишет
в каталог. `analog_suggestions` только читает и возвращает пары-кандидаты;
приложение показывает их тостом «только для ручной проверки».

## Что считается подсказкой

Для SKU без аналогов, блокирование по 3-символьному префиксу
нормализованного артикула, внутри блока:
- тот же нормализованный артикул у другого бренда (score 1.0);
- похожий артикул: difflib ratio ≥ 0.86, разница длин ≤ 2
  («возможна опечатка»).
Пары, уже связанные общим OE, исключены — они и так аналоги через OE.
Ответ: GET /analogs/suggestions?limit=N → пары со score и причиной.
