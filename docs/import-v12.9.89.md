# v12.9.89 — Комплект для повторной загрузки (2 файла)

## Что сделано
Кнопка «Выгрузка для повторной загрузки (2 файла)» в блоке готовности экспорта
формирует два CSV со значениями (без формул, без расчётных колонок):

1. `UC_повторная_загрузка_1_прайс_*.csv` — Артикул, Бренд, Название, Цена,
   Себестоимость, Остаток, Продажи. Загружается первым в пустой каталог и
   создаёт SKU.
2. `UC_повторная_загрузка_2_обогащение_*.csv` — Артикул, Бренд, OE-номера,
   Группа артикулов, Аналоги, Название, Категория, ТН ВЭД, вес/габариты,
   Штрихкод, Применимость, Кратность, изображение, категория/тип Ozon.
   Загружается вторым при включённом «Только обогащение по текущему прайсу» и
   дозаполняет SKU по артикул+бренд и OE (v12.9.83/85).

Загруженный так каталог — полноценная база обогащения для следующих файлов
(индексы OE и артикул+бренд строятся по его строкам). Объём выборки — как у
обычного экспорта (фильтр/выделение/всё, без карантина аномалий).

## Сопутствующие правки
- Автосопоставление импорта узнаёт заголовок «Аналоги» как поле `analog_list`
  (раньше уходил в пользовательскую колонку).
- Кратность в комплекте пишется под стандартным именем «Кратность, шт».
