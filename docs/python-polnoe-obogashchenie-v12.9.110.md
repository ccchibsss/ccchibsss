# v12.9.110 — Полное обогащение (Каталог V) на Python-движке

Пункт 2 аудита оптимизаций (docs/python-optimizacii-v12.9.107.md).
Раньше на движке было только OE-обогащение (v12.9.105); теперь — полное,
по правилам браузерного HVC.

## Правила (паритет с приложением)

- Доноры: реестр «Каталог V» (таблица donors, ключ Артикул+Бренд,
  несколько источников на ключ) + транзитивные OE-группы, где продукты
  и доноры — узлы одного графа.
- Категория и ТН ВЭД: по умолчанию только от той же пары Артикул+Бренд
  (настройка приложения enrichCatMode пробрасывается в cat_mode).
  По OE — только при единогласии доноров; конфликт = пропуск и счётчик.
- Название/применимость: пара Артикул+Бренд, иначе самое частое значение
  OE-группы.
- Габариты: цельный комплект той же пары, иначе меньший по объёму
  комплект OE-группы; совместимость с уже заполненными значениями
  обязательна; заполняются только пустые компоненты.
- Аналоги: артикулы OE-группы дописываются (как в enrich_oe).
- Уже заполненные поля никогда не перетираются.

## Механика

- Схема: products дополнен category/tnved/applicability (миграция
  существующих баз через PRAGMA + ALTER TABLE), новая таблица donors.
- Эндпоинты: POST /donors/import, POST /catalog/enrich-full {cat_mode};
  GET /catalog/products отдаёт и новые поля.
- Приложение: кнопка «Python: полное обогащение». Каталог синкается
  общим _syncCatalog (поля расширены), реестр HVC.parts уходит в движок
  донорами (OE связок — из HVC.byArt), результат подмешивается
  _mergeProducts только в пустые поля (список текстовых полей расширен).
- Импорт файлов движком тоже выучил заголовки: Категория, ТН ВЭД,
  Применяемость, Продажи (ALIASES).

## Проверки

- unittest TestEnrichFull: донор пары заполняет название/ТН ВЭД/габариты;
  конфликт категорий двух источников — категория пропущена, конфликт
  посчитан; в artbrand-режиме OE-категория не берётся, в oe-режиме при
  единогласии — берётся; габариты — меньший совместимый комплект группы.
  Движок 22/22, приложение зелёные.
- Живой HTTP-цикл: товар без полей + донор Каталога V → enrich-full
  заполнил название, категорию, ТН ВЭД и габариты; /catalog/products
  отдаёт их обратно.

## Честные границы паритета

- Движок не повторяет DimPolicy/AnomalyDetector (категорийные лимиты
  аномалий габаритов) и evidence-снимки: источники габаритов проще —
  пара, затем OE-группа. Спорные случаи по-прежнему закрывает браузерное
  обогащение и очередь ручной проверки.
- Поле _sources (кто и когда заполнил) в приложении выставляет браузер
  при своём обогащении; движковое подмешивание источник не проставляет.
