# Экспорт v12.9.81 — калькулятор в два листа + группировка колонок

По образцу шаблонов других селлеров калькулятор Ozon разнесён по листам, чтобы
главная таблица была визуально простой.

## Раскладка
- **«Калькулятор» (13 колонок)**: Артикул, Название, Цена (ввод), Скидка акции %
  (ввод), Закупка (ввод) → формулы: Цена после акции, Все затраты ₽/ед,
  Прибыль ₽/ед, Маржа %, Заработок на закупку %, Цена безубыточности,
  Цена для целевой маржи, Примечание.
- **«Вводы и ставки» (12 колонок)**: Артикул, Вес, Длина, Ширина, Высота,
  Вознаграждение %, Реклама %, Остальные %, Логистика и доставка ₽,
  Упаковка и хранение ₽, Возвраты и прочие ₽, Целевая маржа %.
  Главный лист ссылается на него формулами (`'Вводы и ставки'!F2` и т.д.),
  строки совпадают по порядку и артикулу.
- **Группировка**: вес и габариты на листе вводов свёрнуты в группу
  (`outlineLevel` + `hidden`, кнопка «+» в Excel разворачивает). SheetJS сам
  outlineLevel не пишет — его добавляет существующий патч OOXML
  `Exp._patchSimpleXlsx` по новому параметру `colGroups` листа; туда же пишется
  `<sheetPr><outlinePr summaryBelow="0"/>`.

## Проверка
- Стенд на настоящих SheetJS + fflate + `_patchSimpleXlsx` из приложения:
  в сгенерированном файле у свёрнутых колонок стоят `hidden="true"
  outlineLevel="1"`, sheetPr на месте, межлистовая формула
  `ROUND('Вводы и ставки'!F2*2,2)` сериализуется корректно.
- Числовое зеркало формул не менялось: итоги равны v12.9.80
  (агрегаты те же, просто живут на другом листе).
- `node tests/run-tests.js` — OK (добавлены проверки листов, colGroups и
  outlineLevel); `node --check` скрипта приложения — OK.
