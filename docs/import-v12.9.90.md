## Сценарий работы

экспорт комплектом → повторная загрузка пары (прайс первым, обогащение с
«Только обогащение по текущему прайсу») → обогащение по нормализованному OE и
артикул+бренд. Обновление прайса — повторной загрузкой файла прайса.
