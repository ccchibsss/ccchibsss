# v12.9.76 — что ещё ускорено и что осталось

## Реализовано в 12.9.76 (без изменения результатов расчёта)

1. **Пайплайн не упаковывает и не нормализует неизменённые строки.**
   Если набор изменённых строк известен (импорт любого размера, точечные
   исправления), раньше при дельте ≥ 2 % все остальные строки каталога всё равно
   проходили `compactRowNumeric` + `internRowStrings` (≈2,0 с на 200 тыс. строк —
   замер настоящим кодом) и повторную нормализацию артикула/OE. Теперь они
   пропускаются: строка уже упакована прошлым полным проходом (загрузка каталога),
   её расчётные поля никто не трогал. Карантинная проверка аномалий для таких
   строк сохранена. Тяжёлая ветка изменённых строк выполняется в прежнем объёме —
   числа не меняются.
2. **Таргетная группировка OE при любой дельте** (в 12.9.75 — только < 2 %):
   пайплайн группирует OE лишь по связкам из `changedList` импорта.
3. **Отложенные перерисовки после импорта.** `Dash.render()` и `UE.render()`
   вызываются только если соответствующий раздел на экране; скрытый раздел
   перерисует `UI.go` при входе. Снимает полный `Dash.agg` + рендер юнит-экономики
   по каталогу после каждого импорта из раздела «Данные».

Контроль: `node tests/run-tests.js` (статические гарантии + прежний функциональный
тест эквивалентности группировки OE).
