## Одно окно (v12.9.102)

Движок сам отдаёт приложение: `GET /` на 127.0.0.1:8765 возвращает index.html.
`engine/start_app.bat` — один ярлык: скрытно запускает движок (если ещё не
запущен), ждёт готовности и открывает одно окно браузера с адреса движка;
PyEngine в приложении сам определяет тот же origin. Отдельное окно консоли
не нужно; exe собирается с --windowed (иконка в трее — следующий шаг).

## Удобство пользователя (v12.9.103): путь без трения

Проверка всего пути пользователя дала самый удобный сценарий:
1. Один раз `create_shortcut.bat` → ярлык «UNIT CONTROL» на рабочем столе.
2. Дальше только двойной клик по ярлыку: движок находится сам (exe → pythonw →
   python), запускается скрытно, браузер открывается с готовым приложением.
3. **Токен вставлять больше не нужно**: приложение открыто с адреса движка,
   движок сам вшивает токен в отдаваемую страницу (чужой сайт её не прочитает —
   на `/` нет CORS-разрешения). Ручной токен остался запасным путём.
4. Закрыли вкладку — движок остался тёплым; следующий клик открывает мгновенно.
   Полная остановка — `stop_engine.bat`.
5. Нет ни exe, ни Python — лаунчер честно объясняет и открывает страницу загрузки.
