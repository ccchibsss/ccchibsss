# v12.9.105 — Импорт файла и обогащение по OE на Python-движке

Продолжение переноса тяжёлой работы из вкладки в локальный движок
(см. python-perechet-v12.9.104.md). Приложение по-прежнему полностью
работает без движка — кнопки движка лишь предупреждают, что он не запущен.

## Импорт файла целиком на движке

1. Кнопка «Python: импорт файла» (раздел «Данные»), выбор .csv/.xlsx/.zip.
2. Файл уходит бинарно одним запросом (POST /import/file, заголовок
   X-Filename) — разбирает его движок, а не браузер: CSV/XLSX и файлы
   внутри ZIP → SQLite каталога движка.
3. Приложение забирает каталог постранично (GET /catalog/products) и
   подмешивает в таблицу: новые строки добавляются, существующим
   заполняются только пустые поля (название, OE, аналоги, габариты/объём).

## Обогащение по OE в SQL

1. Кнопка «Python: обогатить (OE)»: актуальный каталог уходит в движок
   чанками по 5000 (POST /import/rows).
2. POST /catalog/enrich: таблица oe_links (OE → артикул+бренд),
   транзитивные группы строятся union-find по общим OE — цепочка
   F100–OE1–F200–OE2–F300 даёт одну группу из трёх.
3. Внутри группы заполняются только пустые поля: название (самое частое
   в группе), габариты/вес (донор — та же артикул-группа, иначе первый
   полный в группе), в analog_list дописываются артикулы группы.
   Чужие заполненные поля не перетираются. Автопоиск аналогов запрещён
   по-прежнему: здесь работаем только по явным OE из самих файлов.
4. Результат подмешивается в таблицу только в пустые поля.

## Найденный баг (регрессия, закрыта тестом)

Первая версия POST /import/file зависала: do_POST читал тело запроса
как JSON (_body) до ветки файла, и обработчик файла ждал те же байты
второй раз. Лечение: файл читается один раз отдельной веткой до _body().
Регрессионный тест test_http_import_file_no_hang гоняет настоящий
HTTP-сервер на эфемерном порту и грузит файл через urllib.

## Проверки

- unittest движка: 12 тестов, включая import_file_bytes, транзитивную
  OE-группу (название и габариты подтягиваются через цепочку) и HTTP-тест.
- Тесты приложения зелёные, синтаксис монофайла проверен.
- Живой HTTP-цикл: price.csv (3 SKU) → /import/file imported=3 →
  /catalog/enrich groups=1, analog_list дописан всем трём →
  /catalog/products отдаёт перекрестные аналоги F100/F200/F300.
