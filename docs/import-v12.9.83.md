# Импорт v12.9.83 — первый файл прайс, дальше только обогащение по текущему прайсу

## Правило
- **Первый файл — прайс**: при пустом каталоге импорт создаёт SKU и задаёт
  состав каталога.
- **Все следующие файлы — только обогащение по текущему прайсу**: пока включён
  переключатель «Только обогащение по текущему прайсу, новых SKU не создавать»
  (по умолчанию включён), любой новый файл — весогабариты, OE-кроссы, категории,
  ТН ВЭД, названия, а также файлы с ценой/себестоимостью/остатком — обновляет
  только SKU, которые уже есть в текущем прайсе. Строки вне прайса пропускаются
  и считаются отдельно; в итоге импорта видно, сколько пропущено и почему.
- Выключенный переключатель возвращает прежнее поведение: файл может создавать
  новые SKU.

## Что изменено
- Раньше (v12.9.62) «только обогащение» срабатывало лишь для справочных файлов
  без цены/себестоимости/остатка; файл с ценой всегда создавал новые SKU.
  Теперь условие одно: `enrichOnlyOn && S.rows.length > 0`.
- Подпись и подсказка переключателя в окне импорта переписаны под новое правило.
- Сообщение по итогам: «обогащение только по текущему прайсу: N строк вне
  прайса пропущено, новых SKU не создавалось».
