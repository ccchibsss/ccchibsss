# UC PyEngine — локальный движок UNIT·CONTROL (Python + SQLite)

## Запуск

- **Разработческий**: `run_engine.bat` или `python uc_engine.py serve`
- **Для пользователя (без установки Python)** — два варианта:
  1. `package_portable.bat` → папка **UC-portable**: внутри лежит портативный
     Python (embeddable), пользователь распаковывает и запускает
     `UNIT CONTROL.bat`. Устанавливать не нужно ничего.
  2. `build_exe.bat` → один `UC-движок.exe` (Python вшит в файл).
  Слушает только `127.0.0.1:8765`. Сам интерпретатор Python для движка нужен
  всегда — вопрос лишь в том, что конечный пользователь его не устанавливает:
  он приезжает внутри папки/exe.
- **Планировщик**: `python uc_engine.py watch` — каждые 5 минут: папка
  `engine_data/inbox` → почта → очередь отправки; в 03:00 — бэкап базы.

Токен доступа создаётся в `engine_data/token.txt` — вставьте его в приложение
(раздел «Данные» → Python-движок) один раз.

## Команды

| Команда | Что делает |
|---|---|
| `serve` | HTTP API для приложения: /health, /calc/batch, /import/rows, /outbox, /outbox/process, /mail/check, /folder/check, /backup, /report/summary, /search |
| `watch` | Цикл: импорт из папки и почты, отправка очереди, ночной бэкап |
| `mail` | Одна проверка почты (IMAP) |
| `folder` | Один проход по `engine_data/inbox` |
| `outbox` | Одна обработка очереди отправки |
| `backup` | Снимок базы в engine_data/backups (хранятся 14) |
| `calc` | Самопроверка экономики на демо-строке эталона |

## Настройки (переменные окружения или engine_data/secrets.json)

- Почта: `UC_IMAP_HOST`, `UC_IMAP_USER`, `UC_MAIL_PASSWORD` (пароль приложения!)
- Ozon: `UC_OZON_CLIENT_ID`, `UC_OZON_API_KEY`; WB: `UC_WB_TOKEN`; ЯМ: `UC_YM_TOKEN`
- На Windows секреты рекомендуется держать не в файле, а выдавать движку через
  переменные окружения/DPAPI-обёртку запуска.

**Безопасность отправки**: настройка `dry_run=1` (по умолчанию) — очередь только
журналируется, реальные запросы на площадки не уходят. Боевой режим включается
осознанно: `POST /settings {"settings":{"dry_run":"0"}}` + заданные ключи.

## Тесты

`python -m unittest discover -s engine/tests` — паритет экономики с золотыми
CSV приложения, налоги, WB, импорт/FTS-поиск, идемпотентность очереди.

## Что ещё даёт Python (реализовано или следующий шаг)

Реализовано: SQLite-каталог с FTS5-поиском, импорт CSV/XLSX/ZIP из почты и папки,
экономика с решателем, очередь отправки с идемпотентностью и журналом, бэкапы,
SQL-отчёт. Естественные следующие шаги: ночные автоотчёты Excel на почту,
мониторинг цен конкурентов по расписанию, сверка остатков с учётной системой
по папке обмена и алерты при ошибках отправок.
